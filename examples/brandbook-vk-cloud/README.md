# Пример брендбука VK Cloud

Учебный брендбук для проверки Verstka: на нём видно, как генератор читает брендбук в разных форматах и применяет его
к шаблону. Бренд, цвета, логотипы и правила условные — это **не официальный брендбук VK Cloud**. Логотип — простая
надпись «VK Cloud» шрифтом Play и знак-облако; настоящих товарных знаков здесь нет.

## Что в папке

| Файл | Что это |
|---|---|
| `guideline.pdf` | гайдлайн на 12 страниц формата слайда 16:9: палитра, сочетания, шрифты, логотип, охранное поле, сетка и поля, диаграммы, «как правильно и как нельзя», примеры слайдов, файлы |
| `tokens.json` | те же цвета, шрифты, поля и сетка в формате W3C Design Tokens (`$value`, `$type`, ссылки `{…}`) |
| `tokens-studio.json` | экспорт плагина Tokens Studio для Figma (наборы `global` и `brand`, `$themes`, `$metadata`) |
| `logos/` | четыре логотипа, каждый в SVG и PNG: `primary` — основной, `white` — белый для синего и тёмного фона, `mark` — знак, `mono` — монохром |
| `slides/` | три примера слайдов 1920 × 1080 в PNG: обложка, график с выводом, ключевые показатели |
| `source/build.py` | сборка всех файлов выше из одних данных |

## Бренд коротко

| Роль | Имя | HEX |
|---|---|---|
| основной | VK Blue | `#0077FF` |
| дополнительный | Cloud Blue | `#2787F5` |
| текст | Night | `#0B1220` |
| фон | White | `#FFFFFF` |
| акцент | Pink | `#FF3985` |
| графики | Sky | `#00C2FF` |

- Шрифты: заголовки — VK Sans Display (Bold 700), текст — VK Sans Text (Regular 400), замена — Play. Шрифтов VK Sans
  в примере нет, поэтому образцы в PDF и слайды набраны заменой — Play (лежит в `verstka/fonts/`, лицензия SIL OFL).
- Логотип — в правом нижнем углу, поля — 48 px, сетка — 12 колонок с промежутком 24 px.
- Акцент — только для главного числа; цвета диаграмм — по порядку палитры.

Расхождения с шаблоном VK Tech, на которых проверяется применение брендбука: шрифт заголовков (Play → VK Sans Display)
и второй акцент (`#FF3885` → `#FF3985`). По умолчанию при расхождении важнее брендбук.

## Как Verstka читает каждый формат

Всё читает одна функция — `verstka.brand.read.read_brandbook(путь или ссылка)`; результат — `BrandSpec`
(`verstka/schemas/brand.py`): цвета с ролями, шрифты заголовков и текста с заменой, логотипы с версиями, поля, сетка,
место логотипа, правила и предупреждения. Модель для этого не нужна.

- **PDF** (`guideline.pdf`) — по тексту страниц: HEX, а без него RGB или CMYK; роль цвета — по словам рядом
  («Основной», «Акцент», «Фон»…), если цвет встречается несколько раз — по большинству; шрифты — по названиям рядом со
  словами «Заголовки» и «Основной текст» и «для заголовков», замена — после «Замена»; образец цвета столбиком (HEX, RGB, CMYK
  отдельными строками) — один цвет; CMYK без HEX пересчитывается приблизительно, с предупреждением; поля, сетка, место логотипа и правила — по
  предложениям («Поля — 48 px», «Логотип — в правом нижнем углу», «Не растягивайте…»). Если передать папку для файлов
  (`assets_dir`), логотипы со страницы «Логотип» сохраняются картинками, а версия определяется по самой картинке.
  С включённой моделью (`use_vlm=True`) страницы с палитрой, шрифтами и логотипом смотрит навык `brandbook_reader`
  и уточняет роли и правила; новых цветов модель не добавляет.
- **Токены W3C** (`tokens.json`) — точно, по именам токенов: `color.role.primary` — основной, `color.chart.*` —
  графики, `font.family.heading` — шрифт заголовков, `layout.margin` — поля, `logo.position` — место логотипа.
  Примитивы палитры (`color.palette.*`) — сырьё для ссылок и в палитру не попадают.
- **Tokens Studio** (`tokens-studio.json`) — так же; ссылки пишутся без имени набора (`{palette.vk-blue}`), шрифты —
  типами `fontFamilies`, `fontWeights` и `typography`; читается одна тема из `$themes` (светлая раньше тёмной), а выгрузка в
  нескольких файлах (`$metadata.json`, `$themes.json`, по файлу на набор) — как один файл. Так же читаются Style Dictionary, плоский JSON
  (`{"primary": "#0077FF"}`) и экспорт переменных Figma.
- **Папка или ZIP** (эта папка целиком) — всё сразу: токены (важнее всего), PDF, тема примера PPTX, логотипы из
  `logos/` (в презентацию идёт PNG) и примеры слайдов (цвета с картинок — только если других источников нет). Архив
  распаковывается во временную папку с проверкой путей и размера.
- **Figma по ссылке** — через REST API: переменные и стили цветов и текста. Нужен токен `FIGMA_TOKEN` в `.env`
  (Figma → Settings → Security → Personal access tokens); без него Verstka прямо скажет, что делать. Файл `.fig`
  прочитать нельзя — это внутренний формат Figma; вместо него — ссылка или экспорт токенов JSON.

Проверить чтение без модели и без сети:

```bash
PYTHONPATH="$PWD" .venv/bin/python -c "
from verstka.brand.read import read_brandbook
print(read_brandbook('examples/brandbook-vk-cloud/guideline.pdf').model_dump_json(indent=2))"
```

## Как пересобрать

```bash
python3 examples/brandbook-vk-cloud/source/build.py
```

Нужны Python с пакетом fontTools (контуры букв логотипа берутся из шрифта Play, поэтому SVG не зависит от
установленных шрифтов), `rsvg-convert` (SVG → PNG) и Google Chrome (HTML → PDF и PNG). Палитра, шрифты и правила
заданы в начале `build.py` один раз — PDF, токены, логотипы и слайды из них не расходятся.
