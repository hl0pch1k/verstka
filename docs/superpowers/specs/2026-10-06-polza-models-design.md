# Переход на Polza: три модели вместо цепочки из восьми

Дата: 2026-10-06. Решение владельца: все модели — с Polza.ai (оплата в рублях, один ключ), остаются только
основная, запасная и модель для картинок; OpenRouter, Groq, Cloud.ru, бесплатные и локальные модели удаляются.

## Требования ТЗ (проверено по «4. VK Tech.pdf» и расшифровке встречи с организаторами)

- Только открытые веса с лицензией Apache 2.0 / MIT; LLM / VLM до 35B, text-to-image — до 20B (задача со звёздочкой,
  п. 3.1 ТЗ; на встрече организатор повторил «до 20 млрд параметров»).
- Ограничения на число моделей нет: лимит считается для каждой модели отдельно (ответ организаторов на встрече).
- На отборочном этапе инференс — свой GPU или внешний API-провайдер (только открытые веса до 35B); в финале топ-10
  обязателен инференс VK (Qwen3.8-27B).

## Модели

| Роль | Модель Polza | Веса на Hugging Face | Лицензия | Размер |
|---|---|---|---|---|
| основная (llm, vlm) | `qwen/qwen3.8-27b` | Qwen/Qwen3.8-27B | Apache 2.0 | 27,8B, видит картинки |
| запасная (llm, vlm) | `qwen/qwen3.6-27b` | Qwen/Qwen3.6-27B | Apache 2.0 | 27,8B, видит картинки |
| картинки (t2i) | `tongyi-mai/z-image` | Tongyi-MAI/Z-Image | Apache 2.0 | 6,15B + кодировщик Qwen3-4B ≈ 10B |

Qwen-Image (20,4B + 8,3B) не берём: выше лимита 20B задачи со звёздочкой. Qwen-Image-2.1 — исследовательская
лицензия. Запасная — Qwen3.6-27B: по индексу Artificial Analysis сильнее Gemma 4 31B (37 против 29), тот же формат
ответов, что у основной.

Проверено вживую 2026-10-06: обе текстовые модели отвечают JSON (17+25 → 42) за 1,3–1,4 с и читают текст с картинки;
Z-Image рисует 1280×720 (16:9) за 8,7 с, 1,40 ₽.

## Polza API (что важно коду)

- База `https://polza.ai/api/v1`, `Authorization: Bearer $POLZA_API_KEY`, совместимо с OpenAI.
- Ошибки: `{"error": {"code", "message", "metadata": {"reason", "raw", "provider_name"}}}`.
  - 402 `INSUFFICIENT_BALANCE`: нет средств, исчерпан лимит ключа («лимит» в тексте) — либо резерв параллельных
    запросов (в тексте — зарезервированная сумма, и её возврат покроет запрос): тогда короткая пауза и повтор.
  - 429 двух видов: свой лимит Polza на модель (есть `Retry-After`: до следующей минуты или до полуночи по Москве —
    окно определяется по нему, а не по тексту: дольше 90 с — дневной) и лимит хоста (без `Retry-After`, есть `metadata.provider_name`) —
    основная сразу уступает запасной; последняя делает паузу 5–8 с и ещё одну попытку; два подряд — пауза модели 2 минуты.
  - 408 / 502 / 503 — повтор (503 — не раньше `Retry-After`); 400 / 401 / 403 / 404 / 413 — не повторять; 403 бывает
    и отказом модерации конкретного запроса — это не отказ ключа.
  - За запрос, завершившийся ошибкой, деньги не списываются.
- `usage.cost_rub` — готовая стоимость в рублях в каждом ответе: Verstka считает расходы в рублях.
- Рассуждения выключаются `reasoning: {effort: "none"}` (верхнеуровневый `reasoning_effort` Polza игнорирует).
- Хосты модели выбирает Polza и сама переключается между ними; `provider.ignore` исключает хосты с 4-битными весами
  (`…/fp4`): на них Qwen портила JSON. Список берётся из открытого каталога `GET https://api.polza.ai/v1/models/{id}`
  при первом запросе (без ключа) и перечитывается раз в 6 часов; при сбое хосты не фильтруются, каталог читается снова
  через 10 минут.
- Картинки: `POST /media {model, input: {prompt ≤ 1000 символов, aspect_ratio ∈ 1:1, 4:3, 3:4, 16:9, 9:16}}` →
  готовый ответ или `{id, status: pending|processing}` → `GET /media/{id}` до `completed` (`data: [{url}]`) /
  `failed`; картинку забираем по ссылке (CDN Polza, 7 дней).

## Что меняется в коде

1. `configs/models.yaml` — роли llm и vlm: цепочка из двух моделей Polza; t2i — Z-Image. `configs/models.free.yaml`
   и `configs/models.local.yaml` удаляются. `configs/models.vk.yaml` остаётся профилем финала (та же Qwen3.8-27B на
   инференсе VK — требование ТЗ для топ-10), без других моделей.
2. `verstka/providers`: разбор ошибок Polza (402 резерв / лимит / нет средств, два вида 429, 403 модерации),
   `cost_rub` вместо `cost_usd`, исключение fp4-хостов; удаляется код только удалённых хостов: бесплатные пулы
   OpenRouter, 413/498 Groq, интервалы Cloud.ru, потолок `max_tokens` Groq.
3. `verstka/images/providers.py` — бэкенд `polza_media` (Media API с опросом статуса); удаляются `openrouter_images`
   и `hf_inference`; `openai_images` остаётся для профиля VK.
4. `verstka/api/model_status.py`, `web/src/lib/modelText.ts` — слова о моделях без OpenRouter / Groq / Cloud.ru:
   один сервис Polza, дневной лимит обновляется в полночь по Москве, владельцу — «пополните баланс Polza /
   поднимите лимит ключа / проверьте POLZA_API_KEY».
5. Документация (README, MODELS, ARCHITECTURE, AUDIT), `.env.example`, тесты — под три модели Polza.

## Проверка

Юнит-тесты без сети (провайдеры подменяются); затем рой ревьюеров по направлениям (провайдеры и ошибки, картинки,
интерфейс и тексты, документация и ТЗ, остатки старых хостов); затем живые прогоны на 8 шаблонах через Polza:
время трёх вариантов ≤ 5 минут, доля ответов модели без отката на правила, качество текста и картинок, расходы.
