# Verstka — интерфейс v2 в стиле VK Tech

Дата: 2026-10-04. Ветка `next`. Заменяет визуальную часть `2026-10-02-ui-redesign-design.md`: владелец отклонил v1
(«наляписто и не очень логично», фиолетовая тема вместо VK, «очень в ИИ стиле»). Логика экранов, API и функции v1
сохраняются; меняются оформление, экран сборки и мелочи, которые мешали понимать происходящее.

## 1. Принципы

- **Выглядит как продукт VK Tech.** Токены темы paradigmTech из VKUI (`@vkontakte/vkui-tokens`) в
  `web/tailwind.config.js`: фон страницы `#F6F7FB`, белые карточки, один акцент — синий VK `#0077FF`
  (`#006EE9` для текста), серые VK вместо zinc, радиусы 8/10/12/16, мягкие тени с голубым оттенком `rgba(0,16,61,…)`,
  шрифт Onest (замена VK Sans), заголовки полужирные.
- **Нет «ИИ-эстетики»**: ни фиолетового, ни градиентов как украшения, ни свечений, ни моноширинных «кодовых» подписей,
  ни заголовков капсом с разрядкой, ни печатающегося текста и «вырастающих» слов.
- **Движение по делу** (правила Эмиля Ковальски): появление — `cubic-bezier(0.23,1,0.32,1)` до 300 мс, нажатие —
  `scale(0.97)` 160 мс, ничего не появляется из `scale(0)` (кроме столбиков диаграммы от оси), анимация только у того,
  что действительно пришло, пока человек смотрит; повторный рендер ничего не переигрывает; `prefers-reduced-motion`
  гасит всё до мгновенного или короткого затухания.
- **Логика важнее украшений**: каждый блок отвечает на один вопрос человека, информация не дублируется.

## 2. Экраны

**Создание.** Заголовок «Новая презентация» и одна строка о том, что будет. Три шага-карточки: «Шаблон» (пять обложек
в ряд: четыре и «Все шаблоны»; загрузка своего; окно шаблона со всеми слайдами), «Текст» (поле, «Из файла»,
«Пример», под полем — что в тексте нашлось: слайды, числа, таблицы), «Параметры» (свёрнуты в одну строку). Внизу
закреплена панель: обложка и имя шаблона, число вариантов, «Слайдов» и «Создать презентацию».

**Сборка.** Заголовок страницы — что агент делает сейчас («Читаю ваш текст» → «Продумываю слайды» → «Сверяю план с
текстом» → «Собираю в вашем шаблоне» → «Проверяю каждое число»), рядом процент и «1:42 из 5:00», под ними полоса
прогресса. Слева **раскадровка** прямо на фоне страницы: карточка на каждый слайд в пропорциях шаблона. Пустая
карточка ждёт; когда дизайнер продумал слайд, она заполняется эскизом его формы (столбцы, круговая, таблица, числа,
карточки, этапы…) цветом самого шаблона (`sketchInk`), подпись называет форму; критик ставит «Замечание», правка —
«Переделан»; сверстанный слайд получает галочку; после экспорта на место эскиза проявляется настоящее превью.
Карточка, о которой агент говорит сейчас, обведена синим. Колонки подбираются так, чтобы все слайды были видны сразу
(`fitColumns`). Переключатель вариантов — тот же `Segmented`, что на результате, со статусом каждого варианта.
Справа — **«Как думает агент»**: шаги с номерами, строка на каждый слайд, замечания критика и исправления «→». Это
обязательная часть экрана (владелец настоял сохранить визуализацию рассуждений).

**Результат.** Раскладка редактора без изменений по логике; оформление на токенах VK.

## 3. Что добавлено на сервере ради интерфейса

- `PATCH /api/templates/{id}` `{title}` — своё имя шаблона (`title.txt` рядом с разбором; пустое возвращает имя
  файла). В окне шаблона — карандаш; имя видно везде, где назван шаблон.
- Строки дизайнера для вариантов, которые спланировал сам конвейер (модель выключена, недоступна, не успела):
  `pipeline/generate.py _say_designs`. Без них раскадровка без модели оставалась пустой.
- `GET /api/generations/{gid}/{strategy}/slides` — список готовых превью: экран сборки грузит только их.

## 4. Проверка

`npm test`, `npm run typecheck`, `npm run build`; повтор записанной сборки `/?replay=<id>&speed=3` (только dev);
живая сборка без модели (выключить «Тексты пишет модель») — бесплатно, 15–30 с. Скриншоты 1280×720, 1440×900,
1920×1080; независимая визуальная проверка по чек-листам frontend-design, Emil Kowalski и Vercel.
