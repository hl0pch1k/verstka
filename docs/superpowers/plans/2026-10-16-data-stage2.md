# Вторая ступень: данные и брендбук — план

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development. Задачи одной волны идут
> параллельно в одной рабочей папке, у каждой свои файлы.

**Goal:** Verstka принимает файлы с данными и брендбук и собирает цельную презентацию, где каждый датасет показан уместной
визуализацией с заголовком-выводом — по ТЗ второй ступени (см. описание решения).

**Architecture:** `docs/superpowers/specs/2026-10-16-data-stage2-design.md` — читать первым. Интерфейс — холст v105
(`docs/design/sloi/boards/V2.dc.html`), сценарий и данные — `examples/data-sales-2026/`.

**Tech Stack:** Python 3.11 (pydantic 2, python-pptx, openpyxl, pypdf, pypdfium2, numpy), FastAPI, React+Vite+TS.

## Global Constraints

- Рабочая папка `verstka-dev/.worktrees/ui-sloi`, ветка `data-stage2`. git — только `/Library/Developer/CommandLineTools/usr/bin/git`;
  коммиты по путям (`-F msgfile -- <paths>`), по-русски, без Co-Authored-By; не пушить; GitHub не трогать.
- Python: `../../.venv/bin/python`, `PYTHONPATH="$PWD"`. Веб: `cd web && npx tsc --noEmit && npm run build && npm test`.
- `.env` не читать и не печатать. Модель (Polza) — только где задача прямо требует; проверки — без модели (`--no-llm`,
  `VERSTKA_NO_DOTENV=1`), кроме отмеченных живых прогонов.
- Серверы для проверки — только на своих портах из задачи; API без `.env` (без ключей — без трат); останавливать по PID.
- Интерпретация данных — детерминированный код; модель только формулирует связку и читает PDF-брендбук; без модели всё
  работает.
- Выбор визуализации не зависит от шаблона и формата файла; цель из текста влияет на выбор.
- Тексты для человека — по-русски, спокойно, без англицизмов; ошибки — человеческие.
- Интерфейс — как на холсте v105 и по правилам «Слоёв»: только transform/opacity (кроме сетки колоды и перестроения за ней),
  `cubic-bezier(0.2,0,0,1)`, 160/240/360/520 мс; ничего не выскакивает и не наезжает; помощник открывается из-под колоды,
  содержимое перестраивается непрерывно; без всплывающих уведомлений.
- Лицензии зависимостей — MIT/BSD/Apache. ≤ 5 минут на 3 варианта. Linux.
- Тесты для каждой логики; полный набор unit-тестов Python и веб-тестов перед итогом волны.
