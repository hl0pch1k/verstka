# Интерфейс «Слои» — план внедрения

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or
> superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** заменить веб-интерфейс `web/` утверждённым дизайном «Слои» один к одному, подключив его к настоящему API.

**Architecture:**
- Данные остаются старые: `api.ts`, `types.ts`, `lib/*` и слой данных `store.tsx`.
- Интерфейс пишется заново в `src/ui/`. Стили переносятся с досок почти дословно в `src/styles/`.
- Экран описывается одним состоянием `ui` и чистой функцией геометрии колоды.
- Движение — CSS-переходы досок. Компоненты только переключают классы и `transform`, а `usePresence` держит
  уходящее содержимое до конца анимации.

**Tech Stack:** React 18.3, TypeScript 5.6 (strict), Vite 6. Тесты — esbuild + `node --test` (`web/scripts/test.mjs`).
Сервер — FastAPI (`verstka/api/app.py`).

## Global Constraints

- **Эталон.** Эталон — `docs/design/sloi/`:
  - доски `boards/*.dc.html`, снимки `shots/*.png`;
  - живой прототип `boards/V2.dc.html`: если доска и V2 расходятся в движении или поведении, верно V2.
- **Старый интерфейс удаляется целиком**, смеси старого и нового нет. Отличаться от макета может только
  содержимое, потому что оно настоящее.
- **Шрифты.** Manrope 500/600/700 — основной. Unbounded 600/700 — только акценты: главный заголовок карточки,
  ключевые числа, `p2-cta`, пункты шапки, цифры в кружках.
- **Иконки.** Только линии, без подложки (tint). Сетка 24, круглые концы. Толщина 2 при размере от 18 px, 2.25 при
  14–16 px, 2.5 при 12 px и меньше.
- **Движение.** Только transform и opacity, кривая `cubic-bezier(0.2,0,0,1)`, 160/240/360/520 мс.
  - Плиты и слои ездят 520 мс.
  - Закрываемый слой уезжает непрозрачным и со своим содержимым.
  - Всё, что движется вместе, движется одной кривой. Ничего не появляется рывком.
- **Запреты.** Никаких фиолетовых и «ИИ»-градиентов, свечений, всплывающих уведомлений (тостов). Статус
  показывается строкой рядом с местом действия.
- **Помощник** сужает колоду на ВСЕХ экранах. Содержимое «Создать» и «Сборки» резиновое, ничего не перекрывается.
- **Ширина** — от 1280 px, колода с полями 24 px. Телефон (M-*) не делаем.
- **Тексты интерфейса** — по-русски, как на досках.
- **Git.**
  - Работа в `verstka-dev/.worktrees/ui-sloi`, ветка `ui-sloi`. Git — `/Library/Developer/CommandLineTools/usr/bin/git`
    (ниже `$G`).
  - Коммиты на русском, только своими путями: `$G commit -F msg -- <пути>`. Без строки Co-Authored-By. Push запрещён.
- **Ключи.** Не печатать API-ключи, не читать `.env` в вывод.

  ```ts
  import { useEffect, useState } from "react";
  /** Держит содержимое смонтированным, пока идёт уход (ms), и включает «показ» со следующего кадра после монтирования —
   *  так CSS-переход входа всегда стартует из закрытого состояния. */
  export function usePresence(open: boolean, ms: number): { mounted: boolean; shown: boolean } {
    const [mounted, setMounted] = useState(open);
    const [shown, setShown] = useState(open);
    useEffect(() => {
      if (open) {
        setMounted(true);
        const raf = requestAnimationFrame(() => requestAnimationFrame(() => setShown(true)));
        return () => cancelAnimationFrame(raf);
      }
      setShown(false);
      const t = window.setTimeout(() => setMounted(false), ms);
      return () => window.clearTimeout(t);
    }, [open, ms]);
    return { mounted, shown };
  }
  ```
