# «Слои»: помощник из-под колоды и непрерывное перестроение — перенос на сайт

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** перенести в веб-интерфейс Verstka (`web/`) правки дизайна холста версий 94–100, которые владелец утвердил 15.10 («отлично. можешь вносить все эти правки дизайна на сайт»).

**Architecture:** эталон — `docs/design/sloi/boards/V2.dc.html` (версия 100). Все правки собраны в одном диффе эталона
`.superpowers/sdd/port/v2-v83-v100.diff` (= `git diff 7f823cf HEAD -- docs/design/sloi/boards/V2.dc.html`): CSS (блоки с
комментариями-заголовками, перечислены в задачах), разметка-крючки (`p2-cbox`, `p2-hx`, `hp-tx`/`hp-txw`/`hp-txn`, `hp-wd`/`hp-nw`,
`hp-shade` и т. п.) и логика. Классы веба перенесены с досок дословно, поэтому большая часть CSS ложится как есть; разметка-
крючки переносятся в соответствующие React-компоненты. Механизм «узкая раскладка по целевой ширине + перекрёстное затухание
содержимого + содержимое держит ширину конца хода» (`ui/deck/fit.ts`, `useDeckFit`, `plateWidth`, `data-fit`-подмены на
«Создать», «Сборке», «Подробнее» и в слоях) — именно то, что владелец отверг на холсте («элементы пропадают, слои
пододвигаются и элементы появляются снова»). Он заменяется непрерывным перестроением, как в V2. «Результат» не меняется,
кроме входа и ухода плиты помощника.

**Tech Stack:** React + Vite + TypeScript, CSS в `web/src/styles/*.css`, тесты `node:test` через esbuild (`npm test`).

## Global Constraints

- Эталон — `docs/design/sloi/boards/V2.dc.html` версии 100; при расхождении доски и V2 в движении верен V2.
- Движение: только transform и opacity; исключение — сетка колоды и перестроение содержимого, которое за ней следует (как
  в V2: дорожки сеток с равным числом дорожек, высоты двухкопийных блоков). Кривая `cubic-bezier(0.2,0,0,1)` (`var(--ease)`),
  160/240/360/520 мс; открытие 520 мс, закрытие 340 мс.
- Ничего не «выскакивает», ничего не наезжает; закрываемый слой уезжает непрозрачным и вместе с содержимым.
- Плита помощника НИ В ОДНОМ кадре не рисуется поверх колоды: режим «из-под колоды» (reveal) с тенью края колоды. Режим push и
  свойство доски `hpEnter` НЕ переносятся (владелец оставил reveal).
- Многострочный текст не переносится заново посреди хода: либо ширина, общая для обеих раскладок, либо две копии в одном месте
  (широкая гаснет, узкая проявляется), как в V2.
- Плавность: 60 кадров/с при 1× на «Создать», «Сборке», «Результате», «Подробнее» (p95 и максимум кадра ≤ 17 мс, кроме кадра
  клика); без наследуемых анимируемых свойств на больших контейнерах; закрытые слои и невыбранные вкладки не держат переходов.
- Покой (помощник закрыт и полностью открыт) на всех экранах при 1440×900 совпадает с V2 версии 100 по раскладке.
- «Результат»: всё, кроме входа/ухода плиты помощника и тени края, остаётся как сейчас (в V2 оно не менялось).
- Логотип: «Verstka» 25 px, полоски 5 px (`zoom:1.25` на `.p2-brand`), вместе с наведением и анимацией «Нет связи».
- Ширина окна от 1280; узкие раскладки — на 1440 и 1280.
- Не трогать файлы вне ворктри; git — только `/Library/Developer/CommandLineTools/usr/bin/git`; коммиты по путям, по-русски, без
  Co-Authored-By; не пушить; GitHub не трогать. Ключи и `.env` не читать и не печатать. Без трат на модели.
