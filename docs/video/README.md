# Видео работы сервиса

[`verstka-demo.mp4`](verstka-demo.mp4) · 8 мин 08 с · [смотреть в браузере](https://cdn.jsdelivr.net/gh/hl0pch1k/verstka@9080ea9/docs/video/verstka-demo.mp4)

Запись экрана живого сервиса в браузере Chrome: один непрерывный дубль, без монтажа и без ускорения. Поверх экрана добавлены только подписи к шагам, курсор и титры в начале и в конце.

## Часть 1 · шаблон VK Tech из датасета

1. Шаблон VK Tech уже разобран сервисом: палитра, шрифты, сетка, макеты.
2. Текст — питч Verstka на 10 слайдов с текстом для докладчика: [`examples/briefs/verstka_final_pitch.md`](../../examples/briefs/verstka_final_pitch.md).
3. «Создать презентацию»: время считается от нажатия, три варианта генерируются параллельно — 1 мин 25 с, оценки проверки качества 100 · 100 · 100.
4. Каждый слайд трёх вариантов на весь экран.

## Часть 2 · шаблон, которого сервис никогда не видел

1. Загрузка «Dark Minimalist Business» с [SlidesCarnival](https://www.slidescarnival.com): его нет в датасете и в регрессионном корпусе, под него ничего не настраивалось. Шаблон разбирается на глазах.
2. Тот же текст, «Создать презентацию» — 1 мин 5 с, оценки проверки качества 100 · 100 · 100.
3. Каждый слайд трёх вариантов на весь экран; «Почему так», ход работы агента, что сервис понял из шаблона, проверка качества, паспорт запуска с моделью и временем по этапам.
4. HTML-версия варианта, правка слайда словами в чате — 26 с, скачивание PPTX.

Файлы обоих прогонов — PPTX, PDF, HTML, отчёты проверки и паспорта запуска — в [`examples/outputs/video/`](../../examples/outputs/video). Модель и настройки — в [MODELS.md](../../MODELS.md#сервис-api-модель-и-настройки-демо-прогонов).
