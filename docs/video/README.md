# Видео работы сервиса

[`verstka-demo.mp4`](verstka-demo.mp4) · 9 мин 46 с · [смотреть в браузере](https://cdn.jsdelivr.net/gh/hl0pch1k/verstka@3ec42ab/docs/video/verstka-demo.mp4)

Запись экрана живого сервиса в браузере Chrome: один непрерывный дубль, без монтажа и без ускорения. Поверх экрана добавлены только подписи к шагам (сверху по центру), курсор и титры в начале и в конце.

## Часть 1 · шаблон VK Tech из датасета

1. Выбор шаблона VK Tech и кнопка «Разбор шаблона»: что сервис прочитал из файла — формат, шрифт, палитра, все макеты и правила оформления.
2. Текст — питч Verstka на 10 слайдов с текстом для докладчика: [`examples/briefs/verstka_final_pitch.md`](../../examples/briefs/verstka_final_pitch.md).
3. «Создать презентацию»: время считается от нажатия, три варианта генерируются параллельно — 1 мин 41 с, оценки проверки качества 100 · 100 · 100.
4. Каждый слайд трёх вариантов на весь экран.

## Часть 2 · шаблон, которого сервис никогда не видел

1. Загрузка «Dark Minimalist Business» с [SlidesCarnival](https://www.slidescarnival.com): его нет в датасете и в регрессионном корпусе, под него ничего не настраивалось. Шаблон разбирается на глазах, затем «Разбор шаблона» показывает, что сервис из него понял.
2. Тот же текст, «Создать презентацию» — 1 мин 27 с, оценки проверки качества 100 · 100 · 100.
3. Каждый слайд трёх вариантов на весь экран.
4. Замечания проверки качества. На обоих прогонах этого видео замечаний нет (оценки 100 · 100 · 100), поэтому сервис открывает из «Моих презентаций» презентацию прошлого запуска на VK Tech: у неё одно замечание — «слайд заполнен на 81 %». Включаем «Замечания»: номер на слайде совпадает с пунктом списка справа. «Исправить слайд» — агент (критик → дизайнер → вёрстка → проверка) переделывает только этот слайд за 18 с: «Замечание исправлено · 97 → 100». Прежнюю версию можно вернуть.
5. «Почему так», ход работы агента, проверка качества, паспорт запуска с моделью и временем по этапам; HTML-версия варианта.
6. Правка словами в чате: «На слайде 8: покажи 87 шаблонов, 99 из 100 и 12 форматов крупными цифрами» — 16 с, таблица превратилась в три крупные цифры; скачивание PPTX.

Файлы прогонов — PPTX, PDF, HTML, отчёты проверки и паспорта запуска — в [`examples/outputs/video/`](../../examples/outputs/video). Модель и настройки — в [MODELS.md](../../MODELS.md#сервис-api-модель-и-настройки-демо-прогонов).
