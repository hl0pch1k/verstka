# Сценарий демо-видео (≤ 7 минут, без склеек)

Требование организаторов: непрерывная запись сквозного сценария, в приложении к видео — файлы сгенерированной презентации. Ниже хронометраж с запасом 40 секунд.

## Подготовка до записи

1. `.env` с ключом провайдера, `verstka serve`, интерфейс открыт на <http://127.0.0.1:8000>, масштаб браузера 100%, окно 1920×1080.
2. Рабочая папка чистая: `rm -rf workspace/generations` (разборы шаблонов можно оставить, но в видео показываем загрузку **нового** файла — возьмите шаблон, которого нет в кэше, либо удалите `workspace/templates`).
3. Под рукой: шаблон `VK_WorkSpace_…pptx`, бриф `examples/briefs/vk_workspace_feature.md`, второй шаблон (ЛЦТ) для эпизода «невиданный шаблон».
4. PowerPoint или Keynote открыт заранее — чтобы показать редактируемость без ожидания запуска.
5. Прогон всухую с таймером: разбор шаблона с моделями ≈ 60–90 с, генерация трёх вариантов ≈ 2–3 мин. Пока идёт ожидание — говорим по тексту ниже, пауз в видео быть не должно.

## Что приложить к видео

- `examples/outputs/<шаблон>/<стратегия>/deck.pptx|pdf|html` — 9 колод;
- PPTX, PDF и HTML той генерации, что была в кадре (папка `workspace/generations/<id>/`).

## Риски записи

- Провайдер моделей отвечает медленно → заранее проверить время; при > 4 мин на генерацию уменьшить число слайдов до 10.
- LibreOffice при первом запуске после перезагрузки стартует 10–15 с → один прогон «для прогрева» до записи.
- Не показывать в кадре `.env` и ключ.
